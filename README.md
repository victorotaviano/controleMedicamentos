# 💊 Controle de Medicamentos

## 📌 Descrição do Problema

Muitas pessoas, especialmente idosos ou pessoas com rotinas intensas, enfrentam dificuldades para lembrar horários e controlar o uso correto de medicamentos. Isso pode causar esquecimentos, uso incorreto e até riscos à saúde.

---

## 💡 Proposta da Solução

Este projeto consiste em um sistema web simples para controle de medicamentos, permitindo cadastrar, visualizar, editar e excluir medicamentos, além de auxiliar na organização dos horários.

---

## 👥 Público-alvo

- Pessoas que fazem uso contínuo de medicamentos  
- Idosos  
- Cuidadores  
- Qualquer pessoa que queira organizar sua rotina de medicação  

---

## ⚙️ Funcionalidades

- Cadastro de medicamentos  
- Listagem de medicamentos  
- Edição de dados  
- Exclusão de medicamentos  
- Sistema de login  
- Controle de horários  

---

## 🛠️ Tecnologias Utilizadas

- PHP  
- HTML  
- CSS  
- PostgreSQL  
- Git e GitHub  

---

## 📥 Instalação

1. Baixar ou clonar o repositório:

git clone https://github.com/victorotaviano/controleMedicamentos.git


2. Colocar o projeto em um servidor local (XAMPP ou WAMP)

3. Criar o banco de dados no PostgreSQL

---

## ▶️ Execução

1. Iniciar o servidor (Apache)
2. Acessar no navegador:

http://localhost/controleMedicamentos


---

## 🧪 Testes

Para rodar os testes:


C:\xampp\php\php.exe tests/testes.php


Os testes verificam:
- Validação de horários  
- Entrada inválida  
- Casos limite  

---

## 🔍 Lint (Análise de Código)

Para verificar erros de sintaxe:


lint.bat

## 🔄 Integração Contínua (CI)

O projeto utiliza GitHub Actions para executar automaticamente:
